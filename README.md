# Data_science_and_statictics_notebooks
A collection of Jupyter Notebooks covering data science, statistics, data preprocessing, visualization, and beginner machine learning using real-world datasets.

#  Data Science & Statistics Lab Notebooks

This repository contains all the Jupyter Notebook experiments I completed while learning **Data Science and Statistics**. Each practical is focused on understanding concepts through real datasets and hands-on coding.

---

##  What You’ll Find in This Repo

###  Topics Covered

* **Data Handling & Cleaning:** Import data, fix missing values, and prepare datasets  
* **Statistics Basics:** Mean, median, mode, probability, and distributions  
* **Data Visualization:** Create charts with Matplotlib and Seaborn  
* **Machine Learning Intro:** Build and test simple models
